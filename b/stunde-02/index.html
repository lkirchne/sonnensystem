Generics: Die spitzen Klammern

Was bedeutet <Himmelskoerper>?
▼

Was sind Generics?

Generics ermöglichen es, den Datentyp einer Liste festzulegen. Die Syntax sieht so aus:

ArrayList<Datentyp> name = new ArrayList<>();

Die spitzen Klammern <> funktionieren wie ein "Etikett" auf einer Kiste: Nur was draufsteht, darf auch rein!

Beispiele

// Eine ArrayList NUR für Strings
ArrayList<String> namen = new ArrayList<>();
namen.add("Alice");  // ✓ Geht!
namen.add(42);       // ✗ Fehler! Nur Strings erlaubt!

// Eine ArrayList für unsere Planeten
ArrayList<Himmelskoerper> objekte = new ArrayList<>();
objekte.add(new Planet());  // ✓ Geht!
objekte.add("Erde");        // ✗ Fehler! Nur Himmelskoerper!
Warum können wir nicht ArrayList<int> schreiben?
a) Weil "int" zu kurz ist.
b) Weil ArrayLists nur Objekte (Klassen) speichern können, int aber ein primitiver Typ ist.
c) Das geht, man muss nur die Bibliothek importieren.
d) Weil Zahlen in Listen verboten sind.

Die Lösung: Wrapper-Klassen

Da int kein Objekt ist, brauchen wir eine "Objekt-Verpackung" dafür.

Stell dir vor, die primitive Zahl ist loser Sand. Die ArrayList ist ein Regal. Sand fällt durchs Gitter. Wir müssen ihn in eine Kiste packen.

  • int (Zahl) → Integer (Kiste mit der Zahl)
  • double → Double
  • boolean → Boolean
ArrayList<int> zahlen;      // ✗ Geht nicht!
ArrayList<Integer> zahlen;  // ✓ Richtig!

Was geben array.length und list.size() zurück?
a) Beide geben 2 zurück.
b) Array: 10 (Kapazität), ArrayList: 2 (Füllstand)

Die for-each Schleife (Der "Gamechanger")

Statt mit Index i zu hantieren, sagst du einfach:

// "Für jeden Himmelskörper h in der Liste objekte"
for (Himmelskoerper h : objekte) {
    h.bewegung();
}

Das ist viel sicherer und kürzer!

Was macht: for (Planet p : planeten) { p.setFarbe("rot"); }
a) Setzt die Farbe des ersten Planeten auf rot
b) Setzt die Farbe ALLER Planeten in der Liste nacheinander auf rot
d) Macht nichts

Problem: Pegel-Zugriffe ersetzen

Was tun mit pegel-1 in urknall()?
▼

⚠️ Das "Pegel"-Problem

Da wir gleich die Variable pegel löschen, funktioniert Code wie getHimmelskoerper(pegel-1) nicht mehr!

✅ Die elegante Lösung: Lokale Variable

Erstelle das Objekt erst, konfiguriere es fertig, und füge es DANN hinzu.

❌ Alt (Umständlich)

this.addHimmelskoerper(new Planet());
this.get(pegel-1).setX(50);
this.get(pegel-1).setFarbe("blau");

✅ Neu (Sauber)

Planet erde = new Planet();
erde.setX(50);
erde.setFarbe("blau");
// Erst wenn fertig: ab in die Liste!
this.addHimmelskoerper(erde);

Bonus: removeHimmelskoerper()

Jetzt wird's richtig kurz!
▼

Erinnerst du dich an das Verschieben?

Im Array mussten wir beim Löschen alle nachfolgenden Elemente eins aufrücken (`objekte[i] = objekte[i+1]`).

Die ArrayList macht das automatisch!

✅ Neu: Einfach mit ArrayList

public void removeHimmelskoerper(int index) {
    if (index >= 0 && index < objekte.size()) {
        objekte.remove(index); // Erledigt ALLES automatisch!
    }
}
