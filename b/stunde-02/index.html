Array vs. ArrayList: Das Konzept

Fest oder flexibel? Das ist hier die Frage!
▼

Einstiegsfrage

Erinnere dich an die letzte Stunde: Unser Array hatte eine feste Größe (z.B. 10). Wenn wir einen 11. Planeten hinzufügen wollten, stürzte das Programm ab oder wir mussten tricksen.

Wissen: Array vs. ArrayList

Schau dir die Unterschiede genau an:

Eigenschaft Array [] ArrayList <>
Größe ✗ Fest (muss am Anfang festgelegt werden) ✓ Dynamisch (wächst automatisch mit)
Elemente hinzufügen Kompliziert (Index verwalten) Einfach (add Methode)
Was wird gespeichert? Primitive (int, double) oder Objekte Nur Objekte (Klassen)
Basierend auf der Tabelle oben: Was ist der entscheidende Vorteil der ArrayList?
a) Sie ist schneller im Zugriff.
b) Sie passt ihre Größe automatisch an die Anzahl der Elemente an.
c) Sie hat eine schönere Farbe im Code-Editor.

ArrayList ist ein Objekt

Ein Array ist fest in die Sprache Java eingebaut (erkennbar an den eckigen Klammern []). Eine ArrayList hingegen ist eine richtige Klasse (wie Planet oder String). Das bedeutet, die Variable speichert nur eine Referenz (einen Verweis) auf das Objekt im Speicher.

Was bedeutet es technisch, dass ArrayList eine Klasse ist?
a) Sie hat Attribute und Methoden (wie .add()), und die Variable ist eine Referenz.
b) Sie ist ein primitiver Datentyp wie int.
c) Sie existiert gar nicht wirklich.

Generics: Die spitzen Klammern

Was bedeutet <Himmelskoerper>?
▼

Was sind Generics?

Generics <Typ> funktionieren wie ein Etikett auf einer Kiste. Sie legen fest, was in die Liste darf. Das sorgt für Sicherheit: Du kannst keinen "String" in eine Liste für "Planeten" stecken.

ArrayList<String> namen = new ArrayList<>();
namen.add("Hallo"); // Erlaubt
namen.add(123);     // Verboten (Compiler-Fehler!)

Expertenwissen: Warum überhaupt <...>?

Was passiert, wenn du eine ArrayList ohne Generics deklarierst?

ArrayList liste = new ArrayList(); // Kein <Typ>!
💡 Antwort anzeigen

Ohne Generics kann die ArrayList alles gemischt speichern - Strings, Zahlen, Planeten! Das klingt gut, ist aber gefährlich:

  • Du weißt beim Rausholen nicht, was du bekommst.
  • Der Computer stürzt ab, wenn du versuchst, einen "String" als "Planet" zu behandeln.

Mit <Himmelskoerper> passt der Compiler auf, dass nur Himmelskörper in der Liste landen!

Wichtig: Das Problem mit primitiven Typen

Eine ArrayList kann nur Objekte speichern. Primitive Datentypen wie int, double oder boolean sind keine Objekte.

Deshalb gibt es sogenannte Wrapper-Klassen (Hüllen), die aus dem primitiven Wert ein Objekt machen:

  • int ➔ Integer
  • double ➔ Double
  • boolean ➔ Boolean
Welche Zeile Code ist korrekt, um eine Liste für ganze Zahlen zu erstellen?
ArrayList<int> zahlen = new ArrayList<>();
ArrayList<Integer> zahlen = new ArrayList<>();
ArrayList<Zahl> zahlen = new ArrayList<>();

ArrayList-Methoden kennenlernen

Die wichtigsten Operationen
▼

Methoden-Übersicht

Hier sind die Befehle, die du brauchst:

ArrayList<String> liste = new ArrayList<>();

// Hinzufügen
liste.add("Hallo");      

// Abrufen (statt array[0])
String s = liste.get(0);

// Größe abfragen (statt array.length)
int anzahl = liste.size(); 

// Entfernen
liste.remove(0);

Achtung: Eine ArrayList hat kein Attribut .length!

Wenn du aus Gewohnheit objekte.length tippst, gibt es einen Fehler.

Richtig bei ArrayList: Immer .size() benutzen.

Wichtig: Kapazität vs. Inhalt

Ein Array hat eine feste Kapazität (.length), egal wie viel drin ist (auch wenn alles null ist).

Die ArrayList Methode .size() zählt nur die tatsächlich enthaltenen Elemente (den Füllstand).

Szenario: Ein Array hat Platz für 100 Elemente (Himmelskoerper[] array = new Himmelskoerper[100];). Eine ArrayList ist neu erstellt (ArrayList<Himmelskoerper> list = new ArrayList<Himmelskoerper>();).
In beide fügen wir jetzt genau 3 Namen ein.

Was geben array.length und list.size() zurück?
Beide geben 3 zurück.
Array: 100 (Gesamtplatz), ArrayList: 3 (Füllstand)
Array: 3, ArrayList: 100

Die for-each Schleife

Um alle Elemente einer Liste zu bearbeiten, nutzen wir die moderne "for-each"-Schleife. Man liest sie so: "Für jeden Himmelskörper h in der Liste objekte..."

for (Himmelskoerper h : objekte) {
    h.bewegung();
}

Entscheidungshilfe: Welche Schleife?

Schleifen-Typ Wann benutzen?
For-each
for(Planet p : liste)		 ✓ Wenn du alle Elemente anschauen oder verändern willst.
Das ist der Standardfall!
Normale For
for(int i=0; ...)		 ✓ Wenn du den Index brauchst (z.B. "Lösche jeden 2. Planeten" oder "Gib Planet Nr. 5 aus").
Was passiert in dieser Schleife: for (Planet p : planeten) { p.setFarbe("rot"); }?
Nur der letzte Planet wird rot.
Jeder Planet in der Liste wird nacheinander rot gefärbt.
Es passiert nichts.

Problem: Pegel-Zugriffe ersetzen

Was tun mit pegel-1 in urknall()?
▼

⚠️ Das "Pegel"-Problem

Da wir gleich die Variable pegel löschen, funktioniert Code wie getHimmelskoerper(pegel-1) nicht mehr!

✅ Die elegante Lösung: Lokale Variable

Erstelle das Objekt erst, konfiguriere es fertig, und füge es DANN hinzu.

❌ Alt (Umständlich)

this.addHimmelskoerper(new Planet());
this.get(pegel-1).setX(50);
this.get(pegel-1).setFarbe("blau");

✅ Neu (Sauber)

Planet erde = new Planet();
erde.setX(50);
erde.setFarbe("blau");
// Erst wenn fertig: ab in die Liste!
this.addHimmelskoerper(erde);

Bonus: removeHimmelskoerper()

Jetzt wird's richtig kurz!
▼

Erinnerst du dich an das Verschieben?

Im Array mussten wir beim Löschen alle nachfolgenden Elemente eins aufrücken (`objekte[i] = objekte[i+1]`).

Die ArrayList macht das automatisch!

✅ Neu: Einfach mit ArrayList

public void removeHimmelskoerper(int index) {
    if (index >= 0 && index < objekte.size()) {
        objekte.remove(index); // Erledigt ALLES automatisch!
    }
}
